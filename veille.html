SpamGPT : L'IA au service des cybercriminels pour le phishing

MalTerminal : Un malware générateur de charges utiles basé sur GPT-4

Des chercheurs en cybersécurité ont mis en lumière MalTerminal, un malware qui utilise l'API de GPT-4 pour générer et modifier dynamiquement des scripts d'attaque (reverse shells et ransomwares). Ce logiciel montre les défis de l'analyse comportementale de codes malveillants créés à la volée.

Mac Malware : Contournement des outils d'analyse basés sur l'IA

Découverte d'une variante de malware ciblant macOS conçue spécifiquement pour leurrer les moteurs de détection heuristique dopés à l'intelligence artificielle. Le malware intègre dynamiquement des portions de code sain pour tromper le modèle prédictif des EDR.

27 Juin 2026

GitHub et Claude Code : Vulnérabilité des assistants de codage autonomes

Une étude met en lumière le risque d'exécution involontaire de commandes malveillantes par les assistants IA autonomes (comme Claude Code) lorsqu'ils sont autorisés à interagir directement avec des dépôts Git. L'attaquant peut exploiter des instructions cachées pour compromettre la machine du développeur.
